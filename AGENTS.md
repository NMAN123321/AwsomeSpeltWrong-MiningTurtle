# Repository Instructions

- After completing any requested change in this repository, commit the relevant changes locally before finishing the task.
- Use a concise, descriptive commit message that explains the completed change.
- Do not push commits or otherwise publish repository changes. The user will push manually.
- Do not amend, squash, rebase, or rewrite existing commits unless the user explicitly requests it.
- Before committing, review the staged files and avoid including unrelated user changes.
- Run relevant checks when possible. If a check cannot be run or fails, report that clearly while still preserving the completed work in an appropriate local commit.
